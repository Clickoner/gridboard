# Gridboard

A free planner for your Instagram grid. Drop your pictures in, drag them into the order you want, keep a few layouts to compare, mark what is already posted, and save the grid as an image.

No account, nothing uploaded, nothing to pay. Your pictures stay in your browser.

**Use it:** https://clickoner.github.io/gridboard/

It is one HTML file with no build step. Open `index.html` in any browser and it works the same.

Gridboard is not affiliated with Instagram or Meta.
